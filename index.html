ID Prefix Extraction

By defining a prefix (like DCP_), we can automatically extract a unique ID number from filenames (e.g., DCP_001.jpg becomes ID 001). These IDs are used to build the connections in your map file.

Files that don't match this prefix can still be used as custom images.
